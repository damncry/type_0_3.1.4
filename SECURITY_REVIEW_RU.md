# Проверка безопасности исходников type_0 3.1.3

Этот файл не является гарантией антивирусной сертификации.

## Изменения в упаковке

- Windows EXE собирается через PyInstaller `onedir`, а не `onefile`.
- Удалён ненужный `ExecutionPolicy Bypass` из команды создания ярлыка автозагрузки.
- Исходники не запускают загруженный из сети исполняемый код.
- UI экспортируется локально; при запуске приложения нет необходимости подключаться к внешнему веб-сайту.
- История и настройки хранятся в `%APPDATA%\type_0`.

## Ограничения

Приложение использует перечисление процессов, `psutil`, вызов Windows API для `EmptyWorkingSet`, запуск штатных страниц `ms-settings:` и несколько обратимых пользовательских твиков реестра. Это функциональность системной утилиты, но сама по себе не доказывает отсутствие ложного или истинного обнаружения.

Если Microsoft Defender сообщает конкретное имя угрозы для нового EXE, не отключайте защиту и не добавляйте широкие исключения. Сохраните путь и имя обнаружения; при подозрении на ложное срабатывание передайте файл Microsoft через официальный портал отправки образцов.


## Примечание к сборке 3.1.3

Портативный Node.js для сборки скачивается только из официального источника Node.js и проверяется по SHA-256. Он находится в `.build_tools` и не включается в конечное приложение. Python-зависимости устанавливаются до проверки Node.js, что исключает прежнюю цепочку отказа `Node missing -> pywebview missing -> no UI bundle`.


## Дополнение к версии 3.1.4

В этой версии изменена частота опроса и очередность сбора телеметрии, добавлены фоновые потоки для сбора CPU/RAM и списка процессов, а также приостановка опроса на время перетаскивания окна. Изменения не отключают антивирусную защиту, не добавляют сетевой функциональности и не меняют список разрешённых действий Windows. Это инженерное описание изменений, а не сертификат антивирусной безопасности.
