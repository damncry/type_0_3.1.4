# type_0 3.1.3 — отчёт об интеграции интерфейса

## Источник

Пользовательский архив `optimizacziya-interfejsa-programmy.zip` содержит React/Next.js интерфейс: страницы обзора, процессов, графиков, оптимизации, настроек и истории, общие компоненты, стили, эффекты переходов и иконки. В текущем проекте сохранена визуальная структура этих компонентов.

## Как подключены реальные функции

- `components/type0/system-provider.tsx` вызывает локальный `window.pywebview.api` и не использует случайные значения в пакетной desktop-версии.
- `desktop_backend.py` предоставляет показатели CPU/ОЗУ, список доступных процессов текущего пользователя, очистку рабочих наборов, подтверждённое завершение выбранных процессов, очистку временных файлов, обратимые твики реестра, смену пользовательского фона, открытие системных папок, управление окном и системный трей.
- `core_backend.py` содержит независимую от UI логику, хранение настроек, историю и фильтр системных процессов.
- В обычном браузере без pywebview API интерфейс явно работает как демо-превью. Только установленная Windows-версия подключена к системным действиям.

## Результаты проверок в этой среде

- `core_backend.py`, `desktop_backend.py`, `webview_main.py` компилируются через `py_compile`.
- TypeScript/TSX файлы прошли синтаксический проход `typescript.transpileModule`.
- Python-мост импортирован и тестово вернул ожидаемые ключи начального состояния и снимка системы на этой платформе.
- Полный Next.js build не удалось выполнить, так как npm registry недоступен в среде сборки (`EAI_AGAIN registry.npmjs.org`). Поэтому `out/` и собранные EXE/Setup не включены. Запусти `build_exe.bat` в Windows с доступом к npm registry.

## Основные пути

- UI: `components/type0/`
- Локальный API браузерного интерфейса: `lib/type0/native-api.ts`
- Windows-оболочка: `webview_main.py`
- API операций: `desktop_backend.py`
- системная логика: `core_backend.py`
- сборка: `build_exe.bat`
- установка: `installer.iss`


## Исправления сборки 3.1.3

`build_exe.bat` теперь устанавливает Python-зависимости до проверки Node.js, а при его отсутствии подготавливает локальный Node.js 22 LTS с проверкой SHA-256. `run_app.bat` запускает полную сборку при отсутствии `out\index.html`. Подробный разбор предоставленных журналов находится в `BUILD_DIAGNOSTICS_RU.md`.
